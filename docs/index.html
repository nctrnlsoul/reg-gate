How a status is decided

Only watched regulators count: SEC, CFTC, Treasury, OCC, FDIC, the Fed, FinCEN, OFAC, CFPB, IRS and the White House.

Matching document typeStatus
  • Silence blocks. No report, or one older than the freshness limit, reads BLOCK everywhere.
  • A BLOCK latches until a human reviewer clears it, and a cleared document still reads REVIEW, never OK.
  • Only Chainlink's forwarder can write, for this chain, with a strictly newer timestamp each time.
  • This page fails closed too. If it cannot read the chain it shows UNKNOWN, never OK.

How it runs

  1. Fetch

    Every node in the Chainlink DON pulls the same finished window of Federal Register publications.

  2. Classify and agree

    A deterministic rules engine sorts them into four categories. Nodes must agree byte for byte. No LLM decides.

  3. Write and enforce

    The signed result lands in the RegGateStatus contract. Tokens ask it before each transfer.

  4. Re-check on override

    When a reviewer clears a BLOCK, that event triggers the workflow again within minutes.
